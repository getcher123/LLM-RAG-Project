## Базовое техническое задание (ТЗ)
Проект: RAG-система для чатбота-консультанта в индустрии развлечений
Язык интерфейса: русский
Фокус: техническая реализация, open-source стек (кроме генерации ответа), умеренные ресурсы
### Ключевые параметры по стэку и данным
- ASR: Whisper v3 Medium (локально; допускается faster-whisper/ctranslate2)
- Нормализация транскриптов: Mistral-7B Instruct
- Эмбеддинги: intfloat/multilingual-e5-large-instruct
- Векторное хранилище: ChromaDB
- Оркестрация: LangChain
- Генерация ответов: ChatGPT API (GPT-4o / GPT-4-turbo)
- Чанки: 200–300 слов (overlap 1–2 предложения)
### 1) Цель проекта
Создать прототип русскоязычного RAG-чатбота, отвечающего на вопросы об индустрии развлечений на основе собственного корпуса: транскрибированное аудио + текстовые документы.
### 2) Основные задачи
- Получить корпус из аудио: распознавание речевых файлов → транскрипты с таймкодами/спикерами.
- Нормализовать транскрипты: пунктуация, регистр, ITN (числа/даты), правки частых ASR-ошибок.
- Разбить все тексты на чанки 200–300 слов (overlap 1–2 предложения) и сохранить метаданные.
- Вычислить эмбеддинги (E5-large-instruct) и проиндексировать в ChromaDB.
- Реализовать онлайн-RAG: векторизация запроса → top-K retrieval → промпт с контекстом → ChatGPT ответ.
- Собрать чат-интерфейс (Gradio).
- Провести тестирование: Retrieval (Recall@K/Precision@K) + Human Eval генерации.
### 3) Архитектура
#### 3.1) Ingest-трак (офлайн)
##### A. Распознавание аудио (ASR) — Whisper v3 Medium
- Вход: аудио/видео файлы (mp3, wav, m4a, mp4 и др.).
- Предобработка аудио:
  - ресемплинг до 16 кГц, моно;
  - при длинных файлах — сегментация на ~30 мин фрагменты (перекрытие 1 мин).
- Модель: Whisper v3 Medium (локально). Допускается ускоренный бэкенд faster-whisper (CTranslate2) для CPU/GPU с FP16/INT8.
- Параметры инференса (рекомендации):
  - language="ru"; task="transcribe" (перевод отключён);
  - beam search beam_size=5–8, best_of=5;
  - температурный режим: temperature=0.0→0.2→0.4 (повышать при неуверенности);
  - включить word/segment timestamps;
  - учитывать no_speech_prob для отсечения тишины;
  - опционально condition_on_previous_text=True для цельности длинных сессий.
- (Опц.)+ кластеризация эмбеддингов; результат —
Выход ASR: JSON/JSONL со структурой:
```json
{
  "file_id": "...",
  "language": "ru",
  "full_text": "Склеенный текст по сегментам..."
}
```
Качество/производительность:
- GPU 8–12 ГБ — рекомендовано; CPU возможен через faster-whisper (медленнее).
- Пакетная обработка файлов; параллелизм по файлам; контроль памяти (батчи сегментов).
- Логи: длина, язык, WER на валидационных отрывках (если есть эталон), доля «no_speech».
##### B. Нормализация транскриптов — Mistral-7B Instruct
- Цель: восстановление пунктуации/регистра, ITN (числа/даты/единицы), единообразие терминов («Marvel»/«Марвел»), правка распространённых ASR-ошибок.
- Подход: батч-обработка сегментов/абзацев промпт-шаблоном:
«Нормализуй русский транскрипт: поставь пунктуацию, исправь регистр, числа и даты, не меняй смысл. Верни только текст».
- Выход: чистый «литературный» текст + карта соответствия сегментам (для таймкодов/спикеров).
##### C. Чанкинг и метаданные
- Чанки: 200–300 слов, overlap 1–2 предложения; избегать разрезов посреди мысли.
- Метаданные на чанк: source_id, type (audio/text), title, speaker(s), time_start/end (если из аудио), date, category (кино/сериалы/музыка), tags.
- Глоссарий терминов: словарь синонимов/вариантов (MCU ⇄ «киновселенная Marvel» и т.п.) — использовать на шаге нормализации (замены/алисы).
##### D. Эмбеддинги и индекс
- Эмбеддинги: intfloat/multilingual-e5-large-instruct (HuggingFace).
- Инструкционное кодирование: для запросов добавлять префикс `query:` , для документов — `passage:` (рекомендованный формат E5).
- L2-нормализация векторов.
- Индекс: ChromaDB (персистентно на диске).
- Схема: id, embedding, text, metadata (см. выше).
- Поддержка фильтров по метаданным (категория, спикер, диапазон дат/таймкодов и т.п.).
#### 3.2) Query-трак (онлайн)
- Получить вопрос → подготовить текст запроса (`query: <вопрос>`) → эмбеддинг (E5).
- Поиск в ChromaDB: top-K (рекоменд. 5–8), опц. фильтры по метаданным.
- Сформировать промпт для генерации:
  - роль/инструкция (RU): «Отвечай на основе контекста. Если ответа нет в контексте — скажи, что не знаешь...»
  - «Вопрос пользователя: ...»
  - «Контекст (нумерованный список кратких фрагментов)»
- Генерация: ChatGPT API (GPT-5 / GPT-5-turbo), temperature=0.2–0.5, max_tokens по ограничению.
- Пост-обработка: форматирование списками/таблицами; (опц.) приложить источники (title + ссылка/таймкод).
### 4) Технический стек и компоненты
- ASR: Whisper v3 Medium
- Фреймворки: openai-whisper / faster-whisper (CTranslate2), torchaudio, librosa, Silero VAD (опц.), pyannote (опц.).
- Нормализация: Mistral-7B Instruct (локально; возможно 4-бит квантование).
- Эмбеддинги: intfloat/multilingual-e5-large-instruct (HF Transformers / SentenceTransformers).
- VectorStore: ChromaDB (PersistentClient, коллекции с метаданными, фильтры).
- Оркестрация: LangChain (TextSplitter, HuggingFaceEmbeddings, Chroma, RetrievalQA/Runnable).
- Генерация: ChatGPT API (модели GPT-4o / GPT-4-turbo).
- UI: Gradio (чат, показ источников, предпросмотр таймкодов).
### 5) Интерфейс и UX
- Поле ввода вопроса, окно ответа.
- Под ответом: «Использованные источники» — название документа / спикер / таймкод (для аудио).
- В таблицах: названия, даты, награды и т.п.; кликабельные таймкоды (при наличии плеера).
### 6) Тестирование и качество
#### ASR
- Набор эталонных отрывков (5–10 мин) для оценки WER;
- Проверка корректности таймкодов (рассинхрон < 0.5 сек на сегмент);
- Доля «no_speech» сегментов, устойчивость к шуму.
#### Retrieval
- 30–50 контрольных вопросов: Recall@K (основная), Precision@K;
- Проверка полезности метаданных и фильтров; сравнение K=5/8/10.
#### Generation (Human Eval)
- Фактическая корректность (подкреплена контекстом), полнота, ясность/стиль;
- Edge-кейсы: местоимения без референта, отрицательные вопросы, запросы вне домена;
- Логи: вопрос, top-K контексты (id+сниппеты), итоговый промпт, ответ.
### 7) Нефункциональные требования
- Запуск на одном ПК/ноутбуке с GPU 8–12 ГБ (желателен для ASR и Mistral); CPU-режим допустим (медленнее) через faster-whisper + квантование.
- Персистентность индекса (ChromaDB на диске), воспроизводимость пайплайна.
- Конфигурируемость через .env/YAML (пути к данным, размеры чанков, K, параметры моделей).
### 8) План реализации (итерации)
#### Итерация 1 — ASR & Корпус
- Скрипт пакетного ASR: загрузка аудио → VAD → Whisper v3 Medium → JSON/JSONL с сегментами/таймкодами/спикером(опц.).
- Нормализация Mistral-7B: батч-обработка сегментов → «литературный» текст + карта соответствий.
#### Итерация 2 — Индексация
3. Чанкинг 200–300 слов (overlap 1–2 предложения) + метаданные (источник, спикер, таймкоды).
4. Эмбеддинги E5 (формат passage:) → загрузка в ChromaDB (персистентно).
#### Итерация 3 — RAG онлайн
5. Ретривер (E5 query: → Chroma top-K) → промпт → ChatGPT → ответ.
6. Мини-чат (Gradio), показ источников/таймкодов.
#### Итерация 4 — Качество
7. Набор вопросов (30–50) → Recall@K/Precision@K; Human Eval генерации.
8. Тюнинг: K, фильтры по метаданным, промпт-инструкции, форматирование ответа.
### 9) Минимальные спецификации модулей
`asr_batch.py`
- Вход: каталог аудио; Выход: `transcripts/*.jsonl`
- Ключи: `--vad true`, `--segment_sec 60`, `--language ru`, `--beam 5`, `--timestamps word`
- Поля JSON: `file_id`, `segments[] (start,end,speaker?,text)`, `full_text`
`normalize.py` (Mistral-7B)
- Вход: `transcripts/*.jsonl`; Выход: `normalized/*.jsonl`
- Батч-промпт; контроль длины; лог ошибок/аномалий.
`ingest.py`
- Вход: `normalized/*.jsonl` + текстовые файлы;
- Чанкинг 200–300 слов (overlap), метаданные;
- Эмбеддинги (E5) с `passage:`;
- Запись в ChromaDB (путь к коллекции в конфиге).
`serve.py`
- Эмбеддинг запроса (`E5 query:`) → Chroma top-K → промпт → ChatGPT;
- Параметры генерации; post-format (списки/таблицы);
- Веб-интерфейс (Gradio).
### 10) Риски и меры
- ASR-ошибки → ухудшение поиска: усилить нормализацию, глоссарий брендов/имён; при необходимости донастройка VAD.
- Длинные документы в контексте LLM: строго 200–300 слов/чанк, контролировать K и длину промпта.
- Галлюцинации генератора: строгая инструкция «если нет в контексте — скажи, что не знаешь»; показывать источники.
- Ресурсы: квантование Mistral-7B, faster-whisper, батч-инференс.

## Быстрый старт

- Установка: `python -m venv .venv && .venv/Scripts/activate` (Windows) или `python -m venv .venv && source .venv/bin/activate` (Unix); затем `pip install -r requirements.txt`.
Проверьте пути и модели в `configs/config.yaml`.
- Данные: положите аудио в `data/audio`.
- Запрос (CLI): `python src/serve.py --db data/chroma_db --collection entertainment --question "Кто режиссёр ...?"`.
- UI: `python src/ui.py` и откройте локальный URL.
